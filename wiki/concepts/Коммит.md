# Коммит

## In one sentence

Коммит - это сохранение текущего состояния проекта в Git

## Explanation

Коммит фиксирует изменения, которые внесены в файлы. Это нужно для того, чтобы в будущем можно было вернуться к любой из прошлых версий проекта.
Чтобы создать коммит, необходимо сначала добавить в индекс файлы с помощью команды `git add`, а затем создать сам коммит командой `git commit -m "Пояснение к коммиту"`
	

## Example

Я записал новый конспект с лекции. Чтобы добавить её в коммит, я пишу `git add .`, а затем пишу `git commit -m "Добавил конспект по лекции кибернетика №2"`, теперь это изменение будет видно в истории

## Boundaries and common mistakes

Коммит не отправляет изменения автоматически на GitHub, это делает отдельная команда `git push` уже после коммита
Частой ошибкой может являться неправильное оформление описания к коммиту, по которому через время нельзя будет нормально определить, какое было совершено изменение в проекте
